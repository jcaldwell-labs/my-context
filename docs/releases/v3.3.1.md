# Release Notes: v3.3.1

**Release Date:** 2026-01-22
**Previous Version:** v3.3.0

## Summary

Patch release with 7 bug fixes focused on database backend reliability, plus dependency updates and CI improvements.

## Bug Fixes

### Database Backend

- **fix: Correct active context query in partitions command** (#92)
  - `partitions` command now correctly displays active context per partition
  - Root cause: JSON format mismatch between writer (`"context-name"`) and reader (expected `{"name": ...}`)

- **fix: Implement database backend methods for touches and timestamp queries** (#86)
  - Adds missing `GetTouches()` and timestamp query methods to PostgreSQL backend
  - Closes #70

- **fix: Handle GetActiveContext error in database backend archive path** (#79)
  - Prevents panic when archiving contexts in database mode

### Commands

- **fix: Improve date parsing validation and error messages** (#83)
  - Better error messages for invalid date formats in `--since`/`--until` flags

- **fix: Add mutual exclusion for --archived and --active-only flags** (#81)
  - Prevents confusing behavior when both flags specified

- **fix: Log warning instead of silently skipping contexts in tag filter** (#75)
  - Users now see warnings when contexts can't be processed during tag filtering

### Code Quality

- **refactor: Extract duplicated pattern matching to shared utility** (#77)
  - Consolidates repeated code patterns into reusable functions

- **fix: Align Go version to 1.24 across CI and release workflows** (#44)
  - Ensures consistent Go version across all build environments

## Documentation

- **docs: Add PostgreSQL database backend documentation to README** (#88)
  - Documents `MY_CONTEXT_HOME=db` and partition syntax
  - Covers connection string configuration and environment setup

- **docs: Add jcaldwell-labs feature article** (retro magazine style)
